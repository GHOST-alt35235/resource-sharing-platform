# 资源共享与积分交易平台 - 项目设计文档

## 一、项目概述

### 1.1 项目名称
资源共享与积分交易平台

### 1.2 项目背景
随着互联网的发展，资源共享已成为一种重要的知识传播方式。本平台旨在建立一个基于积分激励机制的资源共享社区，让用户可以上传、分享、下载各类学习资源，并通过积分体系实现资源价值的量化与交易。

### 1.3 技术架构
- **后端技术栈**: Spring Boot 3.2 + MyBatis 3.5 + Sa-Token 1.37 + MySQL 8.0
- **前端技术栈**: Vue 3 + Element Plus + Axios + Vue Router
- **部署方式**: Docker + Nginx

### 1.4 项目进度
目前项目已完成核心功能开发，进度约 **95%**，剩余少量优化工作。

## 二、核心技术实现

### 2.1 MyBatis 数据库 CRUD 操作（15分）

本项目充分利用 MyBatis 实现数据库操作，主要体现在以下方面：

**(1) 实体映射（ORM）**
- 使用 `@Mapper` 注解定义数据访问层接口
- 通过 XML 映射文件或注解方式实现 SQL 语句
- 支持自动驼峰命名转换（`map-underscore-to-camel-case: true`）

**(2) CRUD 实现示例**

```java
// UserMapper.java
@Mapper
public interface UserMapper {
    @Select("SELECT * FROM user WHERE id = #{id}")
    User findById(Long id);
    
    @Insert("INSERT INTO user(username, password, phone) VALUES(#{username}, #{password}, #{phone})")
    @Options(useGeneratedKeys = true, keyProperty = "id")
    int insert(User user);
    
    @Update("UPDATE user SET nickname = #{nickname} WHERE id = #{id}")
    int update(User user);
    
    @Delete("DELETE FROM user WHERE id = #{id}")
    int delete(Long id);
}
```

**(3) 动态 SQL 查询**

```java
// ResourceMapper.java
@Select("<script>" +
        "SELECT * FROM resource WHERE status = 1 " +
        "<if test='keyword != null'>" +
        "AND (title LIKE CONCAT('%', #{keyword}, '%') OR description LIKE CONCAT('%', #{keyword}, '%'))" +
        "</if>" +
        "ORDER BY create_time DESC" +
        "</script>")
List<Resource> search(@Param("keyword") String keyword);
```

**(4) 事务管理**
- 使用 `@Transactional` 注解实现声明式事务
- 在积分转移等关键业务中确保数据一致性

**(1) 控制反转（IoC）**

### 2.3 AOP 面向切面编程（10分）

本项目通过 AOP 实现日志记录功能：

**(1) 切面定义**

```java
@Aspect
@Component
public class LoggingAspect {
    private static final Logger logger = LoggerFactory.getLogger(LoggingAspect.class);
    
    @Pointcut("execution(* cn.edu.wynu.controller..*.*(..))")
    public void controllerPointcut() {}
    
    @Around("controllerPointcut()")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        long startTime = System.currentTimeMillis();
        String className = joinPoint.getTarget().getClass().getSimpleName();
        String methodName = joinPoint.getSignature().getName();
        
        logger.info("[{}] -> {}.{}", LocalDateTime.now(), className, methodName);
        
        Object result = joinPoint.proceed();
        
        logger.info("[{}] -> {}.{} 耗时: {}ms", 
            LocalDateTime.now(), className, methodName, 
            System.currentTimeMillis() - startTime);
        
        return result;
    }
}
```

**(2) AOP 应用场景**
- **日志记录**: 记录所有 Controller 请求（包含用户ID、类名、方法名）
- **异常处理**: 统一处理异常并记录日志
- **性能监控**: 统计接口响应时间
- **权限控制**: 通过 `AdminPermissionAspect` 实现管理员权限校验

### 2.6 人机交互逻辑（10分）

**(1) 用户认证流程**

```
用户注册 -> 验证手机号唯一性 -> 创建用户 -> 赠送初始积分 -> 登录成功
用户登录 -> 验证账号密码 -> 生成 Token -> 返回用户信息
```

**(2) 资源下载流程**

```
用户点击下载 -> 检查资源状态 -> 判断是否免费用户（管理员/上传者/已下载） -> 
[免费]直接下载 | [收费]检查积分余额 -> 扣除积分 -> 奖励上传者 -> 记录下载 -> 返回文件
```

**下载权限判断**：
- 管理员下载：免费
- 上传者下载：免费
- 重复下载：免费（幂等性保证）
- 首次下载收费资源：扣除积分

**(3) 积分交易逻辑**

```
首次下载收费资源:
1. 下载者扣除积分（写入积分流水，type=2支出）
2. 上传者增加积分（写入积分流水，type=1收入）
3. 更新双方用户积分余额
4. 记录下载记录（is_first_download=1，幂等保证）
```

**积分来源**：
- 注册赠送：100积分
- 上传资源奖励：10积分（可配置）

**积分消耗**：
- 下载收费资源：扣除资源标价积分
- 积分直接转移给资源上传者

**(4) 评论互动逻辑**

```
发表评论 -> 存储评论 -> 更新评论计数
点赞评论 -> 检查是否已点赞 -> 更新点赞数 -> 记录点赞关系
```

## 四、数据库设计

### 4.1 核心表结构

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| user | 用户表 | id, username, password, phone, nickname, points, role, status |
| resource | 资源表 | id, title, description, file_id, price, uploader_id, uploader_name, status, download_count |
| points_record | 积分记录表 | id, user_id, username, points, type(1收入/2支出), description, related_id |
| comment | 评论表 | id, resource_id, user_id, username, content, like_count, create_time |
| comment_like | 评论点赞表 | comment_id, user_id（联合主键，防止重复点赞） |
| chat_session | 聊天会话表 | id, user1_id, user2_id, last_message, last_time |
| chat_message | 聊天消息表 | id, session_id, sender_id, content, file_id, send_time |
| upload_file | 文件表 | id, file_name, original_name, file_path, file_size, uploader_id |
| download_record | 下载记录表 | id, resource_id, user_id, username, points, is_first_download（幂等性保证） |

### 4.2 状态码说明

| 表名 | 字段 | 状态值 | 说明 |
|------|------|--------|------|
| user | status | 0 | 禁用 |
| user | status | 1 | 正常 |
| user | role | admin | 管理员 |
| user | role | user | 普通用户 |
| resource | status | -1 | 审核拒绝 |
| resource | status | 0 | 待审核 |
| resource | status | 1 | 已通过 |
| resource | status | 2 | 已下架 |
| points_record | type | 1 | 收入 |
| points_record | type | 2 | 支出 |

## 六、项目亮点

1. **完整的积分体系**: 注册赠送100积分、上传奖励10积分、下载扣费、完整流水审计
2. **幂等性保证**: 通过下载记录表(`download_record`)防止重复扣费，支持重复下载免费
3. **灵活的免费下载策略**: 管理员免费、上传者免费、重复下载免费
4. **RBAC 权限控制**: 支持管理员(admin)、普通用户(user)角色，通过 `AdminPermissionAspect` 实现权限校验
5. **AOP 日志监控**: 记录所有请求的用户ID、执行时间、异常信息，便于系统监控和问题排查
6. **统一异常处理**: 通过 `GlobalExceptionHandler` 实现全局异常捕获和统一响应格式
7. **前后端分离架构**: 前端Vue 3 + Element Plus，后端Spring Boot，RESTful API通信
8. **模块化设计**: 清晰的Controller、Service、Mapper分层架构
